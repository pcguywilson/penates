Import answers from AI chats

Import a Q&A export from ChatGPT or any AI (JSON or Markdown). A match surfaces as a review-flagged draft when the same question appears - never auto-trusted, and you edit before inserting.

How to export + convert your chat
1. Ask your AI: "generate a JSON of every job-application question and my answer from this chat." If it can, great.
2. If not, export the chat (print-to-PDF, the AI's official data export, or a chat-exporter extension), then paste the text back and use the prompt below to convert it.
3. Import the resulting file here.
